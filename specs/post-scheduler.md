# post-scheduler

## 1. [บังคับ] เว็บนี้คืออะไร ใครใช้

เว็บตั้งเวลาโพสต์ลงเพจ Facebook ให้ร้านค้า
เจ้าของร้านล็อกอิน เขียนโพสต์พร้อมรูป เลือกวันเวลา แล้วปล่อยไว้
ตัวส่งเบื้องหลังหยิบโพสต์ที่ถึงเวลาไปยิงขึ้นเพจเอง แล้วบันทึกว่าขึ้นสำเร็จหรือพลาดเพราะอะไร
เปิดเว็บมาเห็นทันทีว่าอะไรรอส่ง อะไรขึ้นแล้ว อะไรพลาด

## 2. [บังคับ] หน้าเว็บทั้งหมด

| path | สาธารณะ/ต้องล็อกอิน | เนื้อหา |
|---|---|---|
| `/login` | สาธารณะ | ฟอร์มอีเมล+รหัสผ่าน |
| `/` | ต้องล็อกอิน | คิวโพสต์เรียงตามเวลา แยกกลุ่ม รอส่ง / ส่งแล้ว / พลาด พร้อมรูปย่อและสถานะ |
| `/new` | ต้องล็อกอิน | เขียนโพสต์: ข้อความ + อัปรูป 1 ใบ + เลือกเพจ + เลือกวันเวลา |
| `/post/<id>` | ต้องล็อกอิน | แก้โพสต์ที่ยังไม่ส่ง เลื่อนเวลา หรือยกเลิก · โพสต์ที่ส่งไปแล้วดูได้อย่างเดียว |

## 4. [บังคับ] ใครล็อกอินได้ ทำอะไรได้

ผู้ใช้ระดับเดียว คือเจ้าของร้าน สร้างบัญชีด้วย seed ตอนติดตั้ง **ไม่มีหน้าสมัครสมาชิก**
ล็อกอินแล้วทำได้ทุกอย่าง: เขียน/แก้/ยกเลิกโพสต์ · เพิ่มหรือปิดเพจ · เปลี่ยนรหัสผ่านตัวเอง
ทุกหน้ายกเว้น `/login` ต้องล็อกอิน คนที่ยังไม่ล็อกอินเปิดหน้าอื่นต้องถูกเด้งไป `/login`

## 5. [บังคับ] "เสร็จ" คือทำอะไรได้บ้าง

1. เปิด `/` โดยยังไม่ล็อกอิน → ถูกเด้งไป `/login`
2. ล็อกอินด้วยบัญชีจาก seed → เข้า `/` ได้ เห็นโพสต์ตัวอย่างอย่างน้อย 1 ใบ
3. เปิด `/new` เขียนข้อความ อัปรูป 1 ใบ เลือกเพจจาก seed เลือกเวลา **ในอนาคต** แล้วบันทึก → กลับมาที่ `/` เห็นใบใหม่อยู่กลุ่ม "รอส่ง"
4. เปิด `/post/<id>` ของใบนั้น แก้ข้อความแล้วบันทึก → `/` แสดงข้อความใหม่
5. ตั้งเวลาโพสต์ให้เป็นอดีต 1 นาที รอรอบตัวส่ง → สถานะเปลี่ยนเป็น "ส่งแล้ว" และ `/mock-feed` มีใบนั้นโผล่ **พร้อมมี `platform_post_id` บันทึกไว้**
6. ตั้งเวลาโพสต์ให้เป็นอดีตเกิน 2 ชั่วโมง รอรอบตัวส่ง → ขึ้นเป็น "พลาด/เลยเวลา" และ **ไม่ถูกส่งย้อนหลัง**
7. รันตัวส่งซ้ำอีกรอบกับโพสต์ที่ส่งไปแล้ว → `/mock-feed` **ไม่มีใบซ้ำเพิ่ม**
8. เปิด `/settings` ปิดเพจ 1 อัน → `/new` ไม่มีเพจนั้นให้เลือกอีก แต่โพสต์เก่าที่ยิงเพจนั้นยังอยู่ใน `/`
9. เปิด `/post/9999` (ไม่มีจริง) → ได้ 404 ไม่ใช่หน้าพัง
10. ยกเลิกโพสต์ที่รอส่ง → หายจากกลุ่ม "รอส่ง" และรอบตัวส่งถัดไปไม่หยิบไปยิง

## 7. สิ่งที่ **ไม่** ต้องทำ

- ไม่ต้องมี Instagram — รอบนี้ Facebook อย่างเดียว
- ไม่ต้องมีผู้ช่วย AI เขียนแคปชั่นหรือสร้างภาพ
- ไม่ต้องมีโปสเตอร์ ครอปรูปเอง หรือคลังรูป
- ไม่ต้องมีหลายรูปต่อโพสต์ (carousel) — 1 ใบพอ
- ไม่ต้องมีขั้นตอนอนุมัติ หรือผู้ใช้หลายระดับสิทธิ์
- ไม่ต้องมีสถิติผลตอบรับ หรือหน้ารายงาน
- ไม่ต้องมีแจ้งเตือนเข้า LINE หรืออีเมล
- ไม่ต้องมีหน้าสมัครสมาชิก และไม่ต้องมีลืมรหัสผ่าน
- ไม่ต้องมีตารางเวลาประจำ หรือปฏิทินลากวาง
- ไม่ต้องเก็บไฟล์บน S3 — ดิสก์ในเครื่องพอสำหรับรอบนี้

## 8. ของนอกที่ต้องต่อ

⚠️ ค่าจริงไปอยู่ใน `.env` ไม่ใช่ในไฟล์นี้

| บริการ | ใช้ทำอะไร | ตัวแปร env |
|---|---|---|
| Meta Graph API | โพสต์ขึ้นเพจ Facebook | `META_GRAPH_VERSION` · `META_APP_SECRET` |
| (ไม่ต่อของจริงก็รันได้) | `POST_PROVIDER=mock` ให้โพสต์ไปโผล่ที่ `/mock-feed` แทน — ค่าเริ่มต้นต้องเป็น mock | `POST_PROVIDER` |

## Stack (ล็อกไว้แล้ว ไม่ต้องแก้)

Next.js 16 (App Router) · TypeScript · Tailwind · SQLite (better-sqlite3, raw SQL)
NextAuth v5 credentials + bcryptjs · รูปเก็บ local disk + sharp บีบตอนอัป
Docker Compose (web + caddy) · migration เป็น .sql + PRAGMA user_version

**Gotchas ที่ต้องทำตาม** (เจอมาแล้วจริงจาก livincolor):
- middleware ต้องเป็น `proxy.ts` ที่ **root** ไม่ใช่ใน `src/` — ไม่งั้น Turbopack dev ไม่รัน = route ไม่ถูก protect
- `bcryptjs` ต้องอยู่ใน `serverExternalPackages` ของ next.config
- `better-sqlite3` ใช้ v12 (prebuilt สำหรับ node 24)
- Docker base image: `node:22-bookworm-slim`
